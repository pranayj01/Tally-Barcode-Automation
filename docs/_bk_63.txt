4.3  Definition - Color
The definition ‘Color’ is useful to determine the Foreground an d Background Color for a Form,
Part, Field or Border , in Display as well as in Print Mode. A Color specification can  be done by
specifying the RGB V alues (the combination of Red, Green and Blue - each value should range
from 0 to 255).
Syntax
[Color : <Color Name>]
RGB    : <Red>, <Green>, <Blue>
Attribute - RGB
This is the second way of specifying color . One can specify the RGB value from a palette of 256
colors to obtain the required color, i.e., the values Red, Green and Blue can each range from 0 to
255. This gives the user the option to select from the wide range of 24 bit colors.
Example:
[Color  : Pale Leaf Green]
RGB  : 169, 211, 211
[Field  : Party Name]
Set as    : $PartyLedgerName
Color     : Pale Leaf Green 
Print FG  : Pale Leaf Green
4.4  Attributes ‘Background’ and ‘Print BG’
The attribute ‘ Background’ is used to set the Background Color of a Form, Part or a Field in
Display mode. The ‘Print BG’ attribute is used to set the Background Color of a Form, Part o r a
Field in Print mode.
Syntax
[Form : <Form Name>]
   Background    : <Color Name Formula> 
   Print BG      : < Color Name Formula>
