1.3  Object Context
Each Interface object exists in the context of a Data Object. A n Interface object either retrieves
information from the Data Object or stores information into the Data Object. The association of the
Interface object with a Data Object can be done at the Report, Part, Line and Field level. All the
methods of the associated Data Object are available in the Interface object, which is said to be in
the ‘Context’ of the associated Data Object.
The data is always retrieved from the database in context of th e current object. All the data 
manipulation operations are performed on the object in context only.
Any expression such as Formulae, Methods and so on which are ev aluated in the Interface
object, will be in the ‘Context’ of the Data Object.

Methods.
